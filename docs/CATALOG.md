# 正式雪板目录操作说明

## 发布流程

1. 从 `data/source-registry.json` 允许的品牌官网采集规格；找不到人民币官网价格时，依次使用品牌授权店、平台品牌官方旗舰店。
2. 将标准化结果写入 `data/catalog-submissions.json`，运行 `npm run catalog:validate`。
3. 通过 `POST /api/admin/catalog/changes` 写入待审核队列。该接口只接受 `ADMIN_EMAILS` 白名单中的已登录用户。
4. 审核员访问 `/admin/catalog`，逐项核对品牌、完整型号、雪季、规格和价格来源，再批准或驳回。
5. 批准后写入正式目录；推荐接口只查询 `published` 状态的数据和 14 天内有效的人民币价格。

## 数据边界

- 唯一身份：品牌、完整型号、雪季、成人受众四项完全一致。
- 规格来源必须为 HTTPS，成人场地板至少包含一个尺码、板腰和承重范围。
- 官网只有外币价格时跳过价格，不做人民币换算。
- 无合格价格的雪板仍可按已核验规格参与推荐，页面显示“暂无已核验价格”。
- 所有变更必须人工批准；内容哈希相同的重复采集不会生成重复待审记录。

## 上线切换

迁移期间 `CATALOG_MODE=demo`，D1 无已发布数据时继续显示带明显标识的演示目录。完成约 300 款逐条审核后，将托管环境设置为 `CATALOG_MODE=database`；此后数据库为空或不可用时服务明确报错，不回退到演示数据。
