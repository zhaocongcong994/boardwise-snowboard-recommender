# 正式雪板目录操作说明

## 发布流程

1. 先从 `data/source-registry.json` 允许的电商平台检索品牌官方店铺；必须同时核验店铺官方身份、完整型号和雪季，命中后采集展示价与商品主页主图。
2. 官方店铺未命中、访问受限或没有该型号时，再从品牌官网采集规格与官网展示价格。外币保留原币种，不换算人民币。
3. 将每个来源的命中、未命中、访问受限或失败结果，以及原始价格和图片 URL，一并写入 `crawlAttempts` 后运行 `npm run catalog:validate`。
4. 通过 `POST /api/admin/catalog/changes` 写入待审核队列。审核员在 `/admin/catalog` 查看爬虫结果和标准化数据，再批准或驳回。
5. 批准后写入正式目录；推荐接口只查询 `published` 状态的数据和 14 天内有效的价格。

## 数据边界

- 唯一身份：品牌、完整型号、雪季、成人受众四项完全一致。
- 规格来源必须为 HTTPS，成人场地板至少包含一个尺码、板腰和承重范围。
- 官网只有外币价格时保留原币种直接展示，不做人民币换算，也不使用该价格执行人民币预算过滤。
- 无合格价格的雪板仍可按已核验规格参与推荐，页面统一显示“暂未获取到价格”。
- 推荐页商品图片只接受已核验品牌官方店铺的商品主页主图；官网图片和第三方店铺图片均不得替代。没有合格主图时显示缺失状态。
- 所有变更必须人工批准；内容哈希相同的重复采集不会生成重复待审记录。
- 宽板和中宽板必须同时保存品牌原始尺码标签（例如 `156W`、`152MW`）与可计算的数值长度，不能只用板腰推断。
- 品牌未提供某一滑行风格的独立评分时写入 `null`，推荐计算临时使用 5/10 中性基线并明确提示；不得把“未提供”写成 0 分。

## 规格标准化

- 品牌原始 10 分制直接保留；5 分制按 `原值 × 2` 转成 10 分制；百分比按 `百分比 ÷ 10` 转成 10 分制。
- `Park` 映射到 `freestyle`，`Pow` 或 `Backcountry` 映射到 `powder`，`Resort` 映射到 `all-mountain`。没有独立 `carving` 指标时保留空值。
- 仅提供类别硬度时，统一使用：Soft / Soft & Playful = 3，Mid-Soft = 4，Medium = 5，Mid-Stiff = 6，Stiff / Stiff & Aggressive = 8。待审数据必须在 `normalizationNotes` 中注明这是项目标准化值。
- 页面文字推导出的适用等级必须标记为“审核前分类”；只有品牌给出结构化等级时，才可记录为官网直接值。
- `2026` 产品年按 `25/26` 雪季记录；页面没有明确产品年或雪季时不得猜测。
- 开放式承重如 `80+ kg` 暂不填造上限；在数据合同支持开放区间前，跳过该尺码并记录原因。

## 上线切换

迁移期间 `CATALOG_MODE=demo`，D1 无已发布数据时继续显示带明显标识的演示目录。完成约 300 款逐条审核后，将托管环境设置为 `CATALOG_MODE=database`；此后数据库为空或不可用时服务明确报错，不回退到演示数据。
